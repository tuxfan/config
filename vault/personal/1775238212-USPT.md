## New Mac setup

Inventory taken 2026-10-14 from an Apple Silicon MacBook Pro. This is a practical checklist, not a byte-for-byte migration. The Git-backed dotfiles already cover Bash, Git, Neovim config, iTerm profiles, scripts, and more, so they are only noted briefly here.

### 1. Start with macOS and developer tools

1. Sign in to Apple ID and turn on the iCloud services you use. Restore personal files from your backup or Migration Assistant; check Desktop, Documents, Photos, Music, and the iCloud Drive contents.
2. Install Xcode from the App Store if needed, then run `xcode-select --install` for command-line tools.
3. Install [Homebrew](https://brew.sh/) (on Apple Silicon it lives under `/opt/homebrew`). Install [JetBrains Mono Nerd Font](https://www.nerdfonts.com/font-downloads); Ghostty uses it. XQuartz is also installed on the current Mac if X11 programs are needed.
4. Move SSH keys/config and GPG keys through a secure backup, set their permissions, and confirm GitHub/work SSH access. Restore Keychain items or sign in to services again. Do not put unencrypted keys in Git.

### 2. Command-line software

These are the main Homebrew packages present on this Mac; Homebrew will pull their dependencies automatically. Choose the ones you still use:

| Area | Formulae |
| --- | --- |
| Everyday CLI | `bash git coreutils eza fd ripgrep less htop lazygit vim fish pass gnupg pipx node` |
| Development | `cmake clang-format llvm ninja go ruby luarocks cmake-language-server` |
| Scientific/HPC | `open-mpi lmod graphviz podman` |
| Writing/media | `aspell asymptote texlive` |
| Other installed direct packages | `aider berkeley-db berkeley-db@5 ffind pcre python@3.10 unzip xterm` |

For example, after installing Homebrew: `brew install bash git coreutils eza fd ripgrep htop lazygit cmake ninja node pipx pass gnupg podman`.

Installed Homebrew casks: `base codex ghostty gimp hdfview karabiner-elements kitty mactex obsidian`. Install any you want with `brew install --cask <name>`. Both MacTeX and the `texlive` formula are present now; decide whether you still need both. `rendercv` is installed through `pipx` (`pipx install rendercv`). Neovim is also installed separately under `/opt/nvim` and `/usr/local/bin`; reinstall it if the system/Homebrew version is insufficient.

The login shell is Homebrew Bash (`/opt/homebrew/bin/bash`). After installing it, add it to `/etc/shells` if necessary, then use `chsh -s /opt/homebrew/bin/bash`.

### 4. Settings and data outside the dotfiles repo

- **Karabiner:** Copy `~/.config/karabiner/karabiner.json`. It contains the current profile, Caps Lock → left Control, mouse-position shortcuts, and Dash-only `j`/`k` arrow mappings. Karabiner needs macOS Input Monitoring/Accessibility permissions.
- **Ghostty:** Copy `~/.config/ghostty/config`; it uses JetBrains Mono Nerd Font. `~/.config/kitty/kitty.conf` is present but appears to be the stock commented template.
- **iTerm2:** After cloning the dotfiles, set its custom preferences folder to `~/.config/bergen/iTerm2/m1-max` (or the appropriate machine profile) and enable loading preferences from that folder.
- **Other app settings:** If important, copy `~/.config/ParaView/`, `~/.config/fish/` (its Fish config initializes Anaconda), and any custom app preferences from `~/Library/Application Support/`. Recreate Podman machines/connections rather than assuming old VM paths will work.
- **Data and accounts:** Reconnect iCloud, OneDrive, Dropbox, Adobe, Microsoft, browsers, Obsidian, and work chat. Check Lightroom catalogs, REAPER projects/plugins, VM images, and other large libraries separately; app installation does not restore them.

### 5. Dotfiles reminder and final checks

Once SSH works, clone `git@github.com:tuxfan/config.git` to `~/.config/bergen`. Its `bin/mklnks` script creates the home-directory links, but it **deletes existing link targets first**, so review any files already on the new Mac before running it. The current checkout has a local modification to `bashrc`; save desired changes before migration, but remove any hard-coded credentials before syncing or sharing it.

Finally, verify the Bash shell, Git/SSH and GPG access, terminal font, Karabiner permissions and shortcuts, cloud sync, and the licensed creative/audio applications you rely on.
